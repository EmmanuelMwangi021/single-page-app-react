# Personal Project Showcase

A responsive React application that allows users to showcase projects, add new projects dynamically, and search through existing projects.


## Project Description

The Personal Project Showcase is a single-page React application built with Vite. It provides a simple and interactive interface where users can:

- View a collection of personal projects.
- Add new projects using a form.
- Search projects dynamically.
- Experience a responsive interface inspired by the provided design mock-up.


## Features

- Display a list of projects.
- Add new projects dynamically.
- Search projects by title.
- Responsive layout for desktop and mobile devices.

## Technologies Used

- React
- Vite
- JavaScript
- CSS
- HTML

## How to Use

### Adding a Project

1. Enter the project title.
2. Enter the project description.
3. Click **Add Project**.
4. The project will immediately appear in the project list.

### Searching

Use the search input to filter projects by title. The list updates dynamically.
